# Project Overview

This project is a website developed with the **Yii2 framework** to collect and visualize information related to the **Russia–Ukraine military conflict**, featuring complete **frontend and backend** implementation.

Instead of using Yii2 templates such as *absolute*, the project is built upon the *advanced* template, with development done directly using **PHP**, **JavaScript**, and **CSS**. The frontend relies heavily on **ECharts** for dynamic data visualization — **this is the core visual highlight of the project**.

# Feature Showcase

## Frontend

### Home Page

The homepage uses **dynamic backgrounds** to display a collection of high-resolution images. The *Become a Member* button serves as the entry point for user registration.
![yii-1](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-1.png)

Between the **timeline** and the **background images**, there are control buttons linking to different chart modules.
![yii-3](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-3.png)

At the bottom of the homepage, a **timeline** layout is used to display news updates.
![yii-4](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-4.png)

#### News Details

In the timeline, only news summaries are displayed. Clicking on an article leads to the detailed news page, which includes **images, titles, and full content**.
![yii-5](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-5.png)

### Map Module

Using **ECharts**, the project dynamically displays **maps** that visualize data on refugees, sanctions, aid, and expenditures. Users can view the relevant statistics for each country, zoom in on regions, and highlight specific nations.
![yii-6](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-6.png)

### Economy, Military, and Diplomacy Modules

**These sections primarily use ECharts bar charts and line charts** to illustrate **data trends and comparisons** over time.
![yii-7](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-7.png)

Hovering the mouse displays precise data values — a built-in feature of ECharts.
![yii-8](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-8.png)

Data highlighting is also supported.
![yii-9](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-9.png)

In addition, both **line** and **bar charts** can be combined in a single visualization.
![yii-10](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-10.png)

### Comment Module

The first feature of the comment module is to **display user comments**, again presented in a **timeline format**.

Each comment shows the **username** and **time of posting**.
![yii-11](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-11.png)

When submitting a new comment, the system **automatically retrieves the username** of the user.
![yii-12](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-12.png)

## Backend

### Database Operations

The backend allows administrators to **create, read, update, and delete** entries in database tables directly.
![yii-13](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-13.png)

### File Upload

The file upload interface enables administrators to upload files. Note that this feature is **restricted to admin users** — regular users do not have upload permissions.
![yii-14](https://raw.githubusercontent.com/TephrocactusHC/mybolgimg/master/yii-14.png)
